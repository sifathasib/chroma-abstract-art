# 🌈 CHROMA // Interactive Abstract Rainbow Art

A breathtaking, interactive 3D chromatic art experience built with **Three.js**, organic noise displacement physics, Web Audio API crystal chimes, and iridescent rainbow shaders.

---

## 🌟 Live Public Experience

👉 **[Experience CHROMA Live](https://sifathasib.github.io/chroma-abstract-art/)**

---

## 🎨 Three Distinct Artistic Dimensions

Users can seamlessly switch between three distinct interactive abstract modes using the top controls:

### 1. 💎 Prism Bloom
* A breathing, liquid-crystal abstract sculpture with dynamic harmonic noise displacement.
* Moving your mouse ripples through the geometric surface, sending waves of chromatic refraction.
* Encased inside a delicate floating iridescent wireframe cage.

### 2. 🌊 Chroma Ribbon
* Multiple endless ribbons of liquid rainbow silk weaving and oscillating through 3D space.
* Driven by parametric curves and evolving color gradients that respond in real time to mouse coordinates.

### 3. ☀️ Kaleido Mandala
* Concentric rings of crystalline geometric petals spinning in kaleidoscopic rotational harmony.
* Petals breathe, expand, and react to cursor movement with harmonic crystal pulses.

---

## ✨ Features & Magic

* **Crystal Chime Audio Engine**: Clicks and interactions trigger ethereal synthesized pentatonic crystal chime harmonies using the browser's built-in **Web Audio API** (zero audio file downloads needed).
* **Rainbow Stardust**: Thousands of luminous particles orbiting in a cosmic field that accelerate with click shockwaves.
* **Color Palette Switcher**: Switch between *Vibrant Rainbow*, *Pastel Aurora*, *Neon Cyberpunk*, and *Golden Sunset*.
* **Custom Morphing & Dispersion Controls**: Real-time sliders to adjust wave speed and color dispersion.
* **Secret Dedication Modal**: A thoughtful pop-up card for creative inspiration.
